# Dev Neupane Portfolio

Static Next.js portfolio built around verified résumé and public-project evidence.

## Development

```bash
pnpm install
pnpm dev
```

## Production

```bash
pnpm lint
pnpm build
```

The production build is exported to `out/` and deployed to GitHub Pages whenever an approved change reaches `main`.

Career claims come from the approved résumé. Project claims come from public source repositories and deployments. Synthetic work samples are labeled clearly. `aiwithdev.com` remains a separate coaching business.
